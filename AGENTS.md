# Agent Instructions for claude-skills

This repository hosts cross-platform UI/UX engineering skills and standalone dependency-stack architects (`tools/composer-maestro`). It is designed to work seamlessly across both Claude Code and Google Antigravity / Gemini CLI.

## Repository Structure & Customization Conventions

- **Claude Code**: Plugins reside under `plugins/<plugin-name>/` with their Claude manifest at `.claude-plugin/plugin.json`, cataloged in `.claude-plugin/marketplace.json`.
- **Antigravity / Gemini CLI**: Customizations are discovered via `.agents/` (`skills.json`, `plugins.json`, and `.agents/skills/`), with native plugin manifests at `plugins/<plugin-name>/plugin.json`.
- **Standalone Tools**: `tools/composer-maestro/` contains standalone CLI architects (`composer_ios.py`, `composer_kmp.py`, `composer_flutter.py`, `composer_web.py`, etc.) powered by `composer_core.py`.

## Rules for Code Changes

1. **Plugin Versioning**:
   - Any modification inside `plugins/<name>/` MUST bump the `version` field in both `.claude-plugin/plugin.json` and `plugin.json`.
   - Update `CHANGELOG.md` and `README.md` to reflect the new version.
   - The CI gate `.github/version-bumped.py` strictly enforces this requirement on every PR and push.

2. **Composer Maestro Architecture**:
   - **Stream Split**: Status banners, progress indicators, fallback warnings, and default interactive stack views go to `stderr` (`log()` in `composer_core.py`).
   - **Piped Artifacts**: `stdout` is reserved exclusively for clean artifacts generated by `--pkg`, `--pubspec`, `--package`, `--toml`, `--dsl`, `--xcode`, `--install`, `--add`, or `--agent-manifest`.
   - **Color Gating**: Colors in `composer_core.py` must key off `sys.stderr.isatty()` (and check `NO_COLOR`).
   - **Curated Fallback Label**: Offline or unresolvable dependencies fall back to `STABLE_DEFAULTS` and must be labeled `[Curated]` (never `[Curated Stable]`, keeping labels truthful when defaults include prereleases).

3. **Validation**:
   Always run all validation suites before committing:
   ```bash
   claude plugin validate .
   claude plugin validate plugins/modern-nav-motion
   python3 .github/validate.py
   python3 .github/version-bumped.py
   python3 -m compileall -q tools/
   ```
